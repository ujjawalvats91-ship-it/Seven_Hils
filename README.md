# Seven Hills Wai — Private Villa Plots

A luxury real estate landing page for **Seven Hills Wai** — a private 40-acre gated hill community in Wai, Maharashtra.

## 🌄 Project Overview

- **Location**: Wai, Maharashtra (RERA No. P52700011037)
- **Features**: NA villa plots from 1,625 sq.ft, 30+ lifestyle amenities, stepped plotting following natural contours.
- **Tech Stack**: Semantic HTML5, Modern CSS (Responsive Design, Custom Properties), Vanilla JavaScript.

## 📁 Project Structure

```text
├── index.html        # Main landing page markup
├── style.css         # Styling and responsive design
├── script.js         # Interactive carousels and smooth scroll behavior
├── .gitignore        # Ignored files
└── README.md         # Project documentation
```

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or run a lightweight local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000` in your browser.
